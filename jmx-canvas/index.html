LAYER 01 // INSTRUMENTATION LEVEL
MBeans — Managed Resources
Managed Beans expose JVM internals as attributes and operations. Each type implements a different contract.
MBean Types
javax.management.StandardMBean
📦
Standard MBean
implements HelloMBean
Fixed interface. Introspected at startup via reflection. Lowest overhead.
javax.management.DynamicMBean
🔄
Dynamic MBean
implements DynamicMBean
Self-describes at runtime via getMBeanInfo(). Flexible schema.
javax.management.openmbean.OpenMBean
🌐
Open MBean
implements DynamicMBean
Uses only open types (CompositeData, TabularData) for interoperability.
javax.management.modelmbean.ModelMBean
🏗️
Model MBean
implements ModelMBean
Fully configurable at runtime. Required by management frameworks (Spring JMX).
Attribute vs Operation Contract
// Attribute: exposed as readable/writable property
// Maps to javax.management.MBeanAttributeInfo

public interface CacheManagerMBean {
  // readable + writable attribute
  int getCacheSize();
  void setCacheSize(int size);
  // read-only attribute (no setter)
  long getHitRate();
}
javax.management.MBeanInfo
MBean Metadata Structure
MBeanInfo→className, description
MBeanAttributeInfo[] — attributes
MBeanOperationInfo[] — operations
MBeanNotificationInfo[] — events
MBeanConstructorInfo[] — constructors

LAYER 02 // AGENT LEVEL
MBean Server — The Hub
Central registry and broker for all MBeans. Mediates all read/write/invoke operations and routes notifications.

javax.management.ObjectName
Registration Sequence
// 1. Obtain the MBean Server
MBeanServer mbs =
  ManagementFactory.getPlatformMBeanServer();

// 2. Instantiate the managed resource
Object cache = new CacheManager();

// 3. Define the ObjectName (domain:key=value)
ObjectName name = new ObjectName(
  "com.app:type=Cache,name=L1");

// 4. Register — triggers MBeanRegistration callbacks
mbs.registerMBean(cache, name);
